## Root cause (checked with tag-policies GET)

The account has governed tag policies on three of the keys our SQL sets, and none of them allows our values:

| Key | Values the SQL sets | Values the policy allows |
| --- | --- | --- |
| `domain` | `underwriting` (47 occurrences) | finance, sales, supply_chain, quality, hr, operations |
| `data_class` | `synthetic` (47) | compensation, payroll, benefits, retirement, hr_sensitive, bu_access, worker_scope, benefits_self, retirement_self, restricted_bu, restricted_geo, compensation_self, payroll_self |
| `subdomain` | `uw_finance` (2), `intake_quote` (2) | customers, operations, revenue, shipments |
| `certified` | `true` (3) | true, false (OK) |

`SET TAGS` appears 18 times in `00_ddl.sql`, 3 times in `10_rate_new_business.sql` and 4 times in `20_metric_views.sql`, so all three SQL tasks would hit this error. TBLPROPERTIES, schema properties and job/warehouse tags are not governed tags and are not affected (the deploy succeeded).
