# Pitch 02 — Internal Field Brief (Databricks only)

Matthew Giglia | Field Engineering · v0.1 · 2026-11-15 · Synthetic, carrier-neutral Databricks point of view


## Why this demo
A reusable, carrier-neutral "underwriting of the future" story any HLS AE/SA/FDE can run in 15 minutes, built entirely from Genie One + governed UC assets. If it's worth building for one customer, it's worth building for all.

## What it proves
- Genie One as a business coworker (files, skills, scheduled tasks, email drafts, artifacts) — not a dashboard.
- Governed math: rating as a UC function, verified answers in a Genie Agent.
- Ontology: shared definitions across underwriting/actuarial/finance.

## How to reuse
- Deploy the bundle (L400-03), run the 8 Genie Code build sessions (L400-01), dry-run the script (L200-07 / L400-02).
- Swap fictional names/assumptions only through bundle variables and the assumption tables.

## Guardrails
- Never show carrier/customer names, vendor names, or real data.
- Never let Genie compute rates freehand — the skill enforces calling the function.
- Artifacts are Beta; keep a backup artifact open.

## Motion after the demo
Working session with underwriting + actuarial + finance → FDE co-development on the customer's method and data (intake agent, governed rating engine, quote artifact, finance views).
